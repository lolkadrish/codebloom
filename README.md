# Следующий шаг — условия в Python

Интерактивный тренажёр на русском: 12 задач, короткая теория и подсказки без готовых решений.

Темы: if/elif/else, диапазоны, and/or, остаток от деления, вложенные условия, проверка ввода и короткая запись выбора.

Код выполняется в браузере с помощью Pyodide 0.27.7 в отдельном Web Worker. Программа проверяется на нескольких наборах входных данных. Редактор помогает с отступами и сообщает конкретную строку ошибки.

Каждый посетитель имеет свои черновики и прогресс в localStorage своего браузера. Готовых ответов и личных данных в репозитории нет.

## Локальный запуск

В папке с index.html запусти:

```text
python -m http.server 8000
```

Открой http://localhost:8000. Для загрузки среды Python нужен интернет.

## Проверка

12 задач проверены на 73 наборах данных. Дополнительно проверены 8 вариантов ошибок, работа Python в браузере, сохранение прогресса, остановка выполнения и мобильный макет.
