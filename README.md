# Условия в Python — два шага на одном сайте

Начало маршрута: https://lolkadrish.github.io/python-next-step/branching/

Второй курс: https://lolkadrish.github.io/python-next-step/

## Учебный маршрут

1. Первый шаг: пять тем, девять задач — if, else, elif, вложенные условия и короткая запись выбора.
2. Следующий шаг: шесть тем, двенадцать задач — границы, and/or, остаток от деления, порядок проверок, вложенный ввод и короткие выражения.

После успешной проверки всех девяти задач первого курса автоматически открывается первая задача второго. Решение только финальной задачи не завершает курс, если другие задания пропущены. Меню позволяет переключаться между курсами и возвращаться к уже пройденным темам.

Оба курса имеют русский, украинский и английский языки; светлую, тёмную, лавандовую и системную темы; интерактивные примеры с подсветкой веток; мини-тесты; три постепенные подсказки на задачу; редактор с подсветкой, отступами и пояснениями ошибок.

Язык и тема общие для обоих курсов. Код, ввод, подсказки, ответы на вопросы и прогресс сохраняются отдельно для каждого курса и языка в localStorage браузера. Сохранения первоначальной русской версии второго курса переносятся автоматически, включая версии проверенных задач. Изменение языка показывает его собственные черновики; старые решения не удаляются.

Python через Pyodide 0.27.7 выполняется в отдельном Web Worker в браузере. Код не отправляется на сервер для проверки. Есть кнопка остановки, ограничение выполнения 12 секунд и ограничение вывода. Интернет нужен для загрузки среды Python и необязательных веб-шрифтов.

## Локальный запуск

Из папки с этим README запусти `python -m http.server 8000`. Открой http://localhost:8000/branching/ и пройди оба курса. Для полной работы маршрута нужны и корневые файлы, и папка branching.

Общий интерфейс и Python worker находятся в branching. content.js содержит первый курс и общий перевод интерфейса; course.js сохраняет первоначальные данные второго курса; advanced-content.js добавляет его переводы и интерактивные примеры. Корневой index.html загружает тот же интерфейс для второго этапа.

## Проверка

21 задача проверена на 357 вариантах ввода и вывода: 119 вариантов в каждом из трёх языков. Проверены 22 вопроса, совместимость русских тестов, перенос старых сохранений и версий задач, общие настройки, переход только после полного завершения первого курса и сохранение результата перед переходом. В браузере проверены реальный автопереход, исполнение Python во втором курсе, английские и украинские ответы, перенос кириллицы и старых подсказок.

Учебная последовательность первого курса основана на https://proginschool.github.io/tutorial/branching.html. Интерфейс, объяснения, переводы и реализация написаны заново. Готовые решения и QA-данные не включены в опубликованные файлы.

Среда Python размещена в runtime/pyodide на том же GitHub Pages. Первичная загрузка больше не зависит от внешнего CDN. Загрузчик показывает подготовку среды, ждёт до двух минут без прогресса и предлагает повтор прямо в панели результата. Содержимое официального архива Pyodide 0.27.7 проверено по SHA-256. Полный архив исходников включает файлы среды для локального запуска.
Если загрузка с GitHub Pages завершается ошибкой или превышает две минуты, автоматически запускается новый worker с той же версией Pyodide из официального jsDelivr CDN. Ошибки обоих источников отображаются в панели результата; повтор начинает новую попытку, код и прогресс сохраняются.

Подробные объяснения для человека без опыта: 7 вводных разделов, словарь сравнений, разбор каждой строки, таблицы вариантов, ошибки и вопросы перед задачей. Объяснения доступны на трёх языках в обоих курсах. Примеры отличаются от заданий, поэтому решения не раскрываются.
