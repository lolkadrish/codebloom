= записывает значение. == проверяет равенство.
Сравнения
== равно!= не равно> / < больше / меньше>= / <= с учётом равенства
Несколько проверок
and — обе верны. or — хотя бы одна верна. not — наоборот.
Отступы: 0 → 4 → 8 пробелов
if temperature < 10:
    if temperature < 0:
        print("Мороз")
    else:
        print("Прохладно")
else:
    print("Можно гулять")
else стоит под своим if. Двоеточие — в конце всей строки условия. После input() и print() двоеточие не ставится.
Остаток от деления
8 % 3 — это 2. Если остаток 0, число делится нацело.
Выбор одной строкой
message = "Тепло" if temperature >= 20 else "Холодно"
Значение, если да → if условие → else значение, если нет. Двоеточия не нужны.
